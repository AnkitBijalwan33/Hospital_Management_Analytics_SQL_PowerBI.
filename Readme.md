# Hospital Patient Management & Medical Analytics System (MySQL)

## 📌 Project Overview
This project is a relational database system designed to manage hospital operations including patients, doctors, departments, appointments, admissions, treatments, medical tests, and billing.  
It also generates medical analytics reports using SQL queries, views, and stored procedures.

Inspired by real hospital systems like AIIMS, Apollo Hospitals, and Sir Ganga Ram Hospital.

---

## 🎯 Objectives
- Manage patient records and hospital workflows
- Ensure data integrity with PK–FK relationships
- Generate analytical insights for hospital performance
- Implement views and stored procedures for patient history

---

## 🛠️ Tech Stack
- **Database:** MySQL Server 8.0  
- **Tool:** MySQL Workbench  

---

## 📂 Database Schema
8 professional tables created:
- Departments  
- Doctors  
- Patients  
- Appointments  
- Admissions  
- Treatments  
- Medical Tests  
- Billing  

---

## 📊 Analytics Queries
- Total hospital revenue  
- Patients per department  
- Doctor revenue performance  
- Average treatment cost  
- Pending bills report  

---

## 📑 Features
- Relational database with PK–FK constraints  
- Complex joins and aggregation queries  
- Views for patient summary  
- Stored procedure for patient history  

---

## 🚀 How to Run
1. Install MySQL Server & Workbench  
2. Run `hospital_management.sql` from **src/** folder  
3. Insert sample data from **data/** folder  
4. Execute queries from **src/queries.sql**  
5. View reports/screenshots in **output/** folder..
